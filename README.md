# Creative Career AI

A social career platform inspired by LinkedIn, combining professional networking, job discovery, and social media features in one platform.

## 🚀 Technologies

React • JavaScript • Node.js • Express.js • MongoDB

## ✨ Features

* 👤 Create and customize professional profiles
* 💼 Find and post job opportunities
* 📝 Create and share posts
* ❤️ Like and interact with posts
* 💬 Social interaction
* 🔍 Discover career opportunities
* 🤝 Connect with other professionals
* 📱 Social-media-style user experience

## 🎯 Project Purpose

Creative Career AI is designed to combine professional networking and social media into one platform where users can showcase their skills, discover jobs, share content, and connect with other people.
