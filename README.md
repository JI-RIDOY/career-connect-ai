# Creative Career AI

## 📌 Overview

Creative Career AI is a social career platform inspired by LinkedIn where users can create professional profiles, find and post jobs, share content, and connect with others.

## 🛠️ Technologies

* React
* JavaScript
* Node.js
* Express.js
* MongoDB

## ✨ Features

* Professional profile creation
* Job searching and posting
* Post creation and sharing
* Like and social interactions
* User connections
* Career opportunity discovery

## 📦 Dependencies

* React
* Express.js
* MongoDB
* Node.js
